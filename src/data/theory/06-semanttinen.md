# HTML-sivun rakenne

Semanttinen HTML antaa sisällölle merkityksen. `header`, `nav`, `main`, `section`, `article` ja `footer` kertovat sekä selaimelle että avustaville teknologioille, miten sivu on rakennettu.

```html
<header>Logo ja navigaatio</header>
<main><section>Sisältö</section></main>
<footer>Yhteystiedot</footer>
```
