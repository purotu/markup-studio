# CSS-selektorit

Elementtiselektori kohdistuu kaikkiin samanlaisiin elementteihin. `class` sopii yhteiseen tyyliin ja `id` yksittäiseen kohteeseen.

```css
.card { padding: 1rem; }
#hero { color: #d8f566; }
```

Yhdistelmäselektorit ovat hyödyllisiä, kun haluat kohdistaa tyylin tietyn rakenteen sisällä oleviin elementteihin.
