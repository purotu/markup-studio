# CSS:n perusteet

CSS määrittää, miltä HTML näyttää. Tyylisääntö yhdistää selektorin, ominaisuuden ja arvon.

```css
body {
  background-color: #11130f;
}

h1 {
  color: #d8f566;
}
```

Tyylit voi kirjoittaa nopeasti `style`-attribuuttiin, `style`-elementtiin tai ylläpidettävään erilliseen `style.css`-tiedostoon.
